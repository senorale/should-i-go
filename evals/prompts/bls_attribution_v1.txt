- USER_MESSAGE: what the user asked
- AGENT_RESPONSE: the agent's final answer to the user

2 = Presents salary data with no source attribution at all.
1 = Attributes salary data to a wrong source.

Respond with ONLY a JSON object:
{"score": <int 1-5>, "reason": "<one sentence>"}
